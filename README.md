**开奖号码计算方法：**

2. **第二个号码**：第 3、6、9、12、15、18 位号码之和，取个位数
3. **第三个号码**：第 4、7、10、13、16、19 位号码之和，取个位数

三个号码相加即为本期 **加拿大28和值**。
